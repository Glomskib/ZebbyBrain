4) Safety net & rollback

Kill switches (feature flags): if any area misbehaves, set its FF to false and restart (fast rollback without redeploy).

Stripe: if you see errors, set FF_REWARDS=false (to stop incentives noise) and pause checkout endpoints temporarily.

Cron: set ENABLE_CRON=false to halt schedulers in an emergency.

5) Monitoring & backups (same day)

Daily DB backup (retain 14–30 days).

Analytics (privacy-first): just counts—signups/day, DAU/WAU, posts/comments/day, referral conversions, exports, AI calls total.
