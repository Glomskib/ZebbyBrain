7) Security & compliance (final pass)

Headers: Helmet/CSP, X-Frame-Options: DENY, Referrer-Policy: no-referrer, X-Content-Type-Options: nosniff.

Cache-Control: no-store on all health-data endpoints and exports.

Stripe: live keys set; webhook verified; idempotency on checkout; no req.body.userId fallbacks anywhere.

Logging: no PII/PHI; redaction in production logs; CSP report endpoint enabled (if configured).

Rate limits confirmed: posts (6/h), comments (20/h), reactions (60/h), reports (10/h), AI endpoints (10/min).

Moderation: your mod queue is live and scoped; abuse reporting works.

8) Data lifecycle & trust

Exports: CSV/PDF already built — keep no-store.

Delete account: soft-delete + 7-day undo (if not added, put on near-term).

Retention: if using 2-year export-and-purge, keep flag off until after launch; message users before enabling.

Backups: confirm DB backup/restore path (Replit DB or external Postgres backup).

9) Payments & rewards guardrails

Stripe: switch plan to live; test success/failure/portal flows.

Rewards anti-fraud: unique signup credit enforced (you added a partial unique index — good); week-active job is idempotent; keep logs minimal.

Referral code TOS: short note on fair use; disallow self-referrals.

10) Analytics & monitoring (minimal, privacy-first)

Basic, non-PII metrics: signups/day, DAU/WAU, posts/comments/day, referral conversions, rewards awarded, AI calls (count).

Error monitoring: even if you don’t add Sentry, ensure server logs surface stack traces with request IDs.

Health endpoint: /api/health returns 200 + headers sanity.
