2) Groups (age/gender-gated)
2.1 DB migrations (Drizzle/SQL; adapt names)
group              (id, slug, name, visibility 'private' default, kind 'age'|'gender', min_age int, max_age int, gender_req 'male'|'female'|null, created_by, created_at)
group_membership   (id, group_id fk, user_id fk, role 'member'|'moderator'|'owner' default 'member', status 'approved'|'pending'|'banned' default 'approved', pseudonym text, created_at, UNIQUE(user_id, group_id))
post               (id, group_id fk, author_id fk, kind 'text'|'poll'|'resource' default 'text', body text, media_url text, created_at, edited_at, INDEX(group_id, created_at desc))
comment            (id, post_id fk, author_id fk, body text, parent_comment_id nullable, created_at, edited_at, INDEX(post_id, created_at asc))
reaction           (id, post_id fk, user_id fk, emoji text, created_at, UNIQUE(post_id, user_id, emoji))
report             (id, target_type 'post'|'comment', target_id, reporter_id, reason_code text, notes text, status 'open'|'reviewed'|'actioned' default 'open', created_at)

2.2 Seeding groups

Age brackets: 0–9, 10–19, …, 70–79, 80+ (kind='age', min_age, max_age).

Adults: Male Only, Female Only (kind='gender', min_age=18, gender_req=male|female).

2.3 Access control

Derive age from profile.birthDate.

For list/join/read: enforce age range and gender requirement on server (never trust client).

Default status='approved' for eligible users; otherwise 403.

2.4 API (rate-limited; all return Cache-Control: no-store)
GET    /api/groups                         # returns only groups user is eligible for
POST   /api/groups/:id/join                # server validates age/gender; idempotent
GET    /api/groups/:id/posts?page=&sort=   # sort=new|top (top = reactions+comments last 7d)
POST   /api/groups/:id/posts               # { body, kind? } sanitize markdown subset (no HTML)
POST   /api/posts/:id/comments             # { body } sanitize
POST   /api/posts/:id/react                # { emoji } upsert per user/post/emoji
POST   /api/report                         # { targetType, targetId, reasonCode, notes? }


Rate limits: posts 6/h, comments 20/h, reactions 60/h per user.

2.5 UI

Groups Directory: show only eligible groups; “Join” (instant if eligible).

Group Page: composer (textarea + emoji), feed, reactions, comment threads (1 level nest), report button.

A11y: keyboard submit (Ctrl/Cmd+Enter), focus management, aria-live on new comments.

2.6 Safety

Markdown whitelist: plain text + line breaks only (no HTML); link parser with rel="nofollow noopener".

Profanity/simple harassment list → auto-flag to report (does not block post).

Minimal mod queue page (list open reports, actions: hide/remove, mark reviewed).

Acceptance

Under-age/incorrect gender cannot access restricted groups (403).

Post/comment/react flows work; sanitizer strips HTML.

Reports create and appear in mod list.
