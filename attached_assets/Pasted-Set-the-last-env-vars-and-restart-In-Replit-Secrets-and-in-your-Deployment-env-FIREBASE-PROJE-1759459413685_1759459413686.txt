2) Quick Firebase auth smoke test (no FlutterFlow needed)

Create a temporary test user in Firebase Auth, then grab an ID token:

# 2A) Exchange email/password for ID token via Firebase REST
curl -s "https://identitytoolkit.googleapis.com/v1/accounts:signInWithPassword?key=YOUR_FIREBASE_WEB_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"email":"test@example.com","password":"yourpass","returnSecureToken":true}' | jq -r .idToken
# copy the printed token into $ID

# 2B) Call your RAG endpoint with the Firebase token
curl -s -X POST https://<your-replit-domain>/api/rag/answer \
  -H "Authorization: Bearer $ID" \
  -H "Content-Type: application/json" \
  -d '{"question":"What are common EDS symptoms?","window":"30d"}' -i
# Expect 200 + X-Queries-Left header
