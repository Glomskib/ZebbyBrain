Title: Zebby • Add PWA icons + wire manifest/SW

Goal: Create required PWA icons, update manifest.webmanifest, and ensure the service worker precaches them so installability passes Lighthouse.

Tasks

Create icons in ZebbyBrain/public/

icon-192.png (192×192)

icon-512.png (512×512)

(nice to have) icon-192-maskable.png, icon-512-maskable.png

Source: if public/logo.svg or public/logo.png exists, use it. If not, create a simple square SVG with a zebra mark + brand colors and rasterize.

Use Node + sharp (add dev dep) to rasterize to exact sizes.

Update ZebbyBrain/public/manifest.webmanifest

Ensure it contains:

{
  "name": "Zebby",
  "short_name": "Zebby",
  "start_url": "/",
  "display": "standalone",
  "background_color": "#0d0f12",
  "theme_color": "#0d0f12",
  "icons": [
    { "src": "/icon-192.png", "sizes": "192x192", "type": "image/png", "purpose": "any maskable" },
    { "src": "/icon-512.png", "sizes": "512x512", "type": "image/png", "purpose": "any maskable" }
  ]
}


Update service worker precache list

In ZebbyBrain/public/service-worker.js, ensure the APP_SHELL includes:

'/icon-192.png',
'/icon-512.png'


Keep the existing rule that bypasses /api/* and exports.

Scripts & build

Add a generate:icons script (runs the sharp script).

Make build run npm run generate:icons first.

Acceptance

DevTools → Application → Manifest shows Installable ✓.

SW installs without asset cache failures.

Icons load at /icon-192.png and /icon-512.png.

Files to add

ZebbyBrain/scripts/generate-icons.mjs

import fs from 'node:fs';
import sharp from 'sharp';

const out = 'ZebbyBrain/public';
const srcCandidates = [
  'ZebbyBrain/public/logo.png',
  'ZebbyBrain/public/logo.svg',
];
let src = srcCandidates.find(p => fs.existsSync(p));

if (!src) {
  // fallback: create a basic SVG tile
  const svg = `<svg xmlns="http://www.w3.org/2000/svg" width="1024" height="1024">
    <rect width="100%" height="100%" fill="#0d0f12"/>
    <text x="50%" y="54%" font-size="520" text-anchor="middle" dominant-baseline="middle" fill="#ffffff">🦓</text>
  </svg>`;
  src = 'ZebbyBrain/public/tmp-logo.svg';
  fs.writeFileSync(src, svg);
}

await sharp(src).resize(192,192).png().toFile(`${out}/icon-192.png`);
await sharp(src).resize(512,512).png().toFile(`${out}/icon-512.png`);
// maskable variants (optional)
await sharp(src).resize(192,192).png().toFile(`${out}/icon-192-maskable.png`);
await sharp(src).resize(512,512).png().toFile(`${out}/icon-512-maskable.png`);

console.log('Icons generated in', out);


Update package.json (root):

{
  "scripts": {
    "generate:icons": "node ZebbyBrain/scripts/generate-icons.mjs",
    "build": "npm run generate:icons && vite build"
  },
  "devDependencies": {
    "sharp": "^0.33.3"
  }
}


Run

npm install

npm run build (or your Replit build command)

Refresh app → Chrome DevTools → Application → Manifest: verify Installable.
