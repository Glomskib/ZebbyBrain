Tasks
1) Migrations

Create tables (names can match your style):

group (id, slug, name, kind:'age'|'gender', visibility:'private', min_age, max_age, gender_req:'male'|'female'|null, created_at)

group_membership (id, group_id fk, user_id fk, role:'member'|'moderator'|'owner', status:'approved'|'pending'|'banned', pseudonym, created_at, UNIQUE(user_id, group_id))

post (id, group_id fk, author_id fk, kind:'text'|'poll'|'resource', body text, media_url text, created_at, edited_at, INDEX(group_id, created_at desc))

comment (id, post_id fk, author_id fk, body text, parent_comment_id null, created_at, edited_at, INDEX(post_id, created_at asc))

reaction (id, post_id fk, user_id fk, emoji text, created_at, UNIQUE(post_id, user_id, emoji))

report (id, target_type:'post'|'comment', target_id, reporter_id, reason_code text, notes text, status:'open'|'reviewed'|'actioned', created_at)

Create tables for referrals/rewards:

add user.referral_code (unique)

referral_event (id, referrer_user_id, referred_user_id, type:'signup'|'week_active', occurred_at)

rewards_ledger (id, user_id, points int, reason:'invite_confirmed'|'active_week', created_at)

2) Seed Groups

Age brackets: 0–9, 10–19, …, 70–79, 80+.

Adult only: Male (≥18, gender=male), Female (≥18, gender=female).

3) Access Control (server)

Derive age from profile.birthDate; derive gender from profile.gender.

Endpoints (all Cache-Control: no-store, rate-limited):

GET /api/groups → return only groups user is eligible for

POST /api/groups/:id/join → validate eligibility; idempotent

GET /api/groups/:id/posts?page=&sort=new|top

POST /api/groups/:id/posts → sanitize text (no HTML)

POST /api/posts/:id/comments → sanitize

POST /api/posts/:id/react → upsert user/emoji

POST /api/report → queue moderation

4) UI

Groups Directory (only eligible groups shown).

Group Page: composer (textarea + emoji), feed, reactions, 1-level threaded comments, “Report” menu.

A11y: Ctrl/Cmd+Enter submit, focus ring, aria-live on new comments.
